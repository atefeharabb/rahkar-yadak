# راهکار یدک — فروشگاه قطعات خودرو

فروشگاه فارسی و راست‌چین قطعات خودرو با Node.js، Express، EJS و SQLite.

## پیش‌نمایش GitHub Pages
فایل `index.html` در ریشه مخزن، یک پیش‌نمایش ایستا از ظاهر فروشگاه است. برای نمایش آن:

1. در GitHub وارد مخزن شوید و به **Settings → Pages** بروید.
2. در بخش **Build and deployment** گزینه **Deploy from a branch** را انتخاب کنید.
3. Branch را روی `main` و Folder را روی `/(root)` قرار دهید و Save را بزنید.
4. پس از انتشار، آدرس GitHub Pages در همان صفحه نمایش داده می‌شود.

> GitHub Pages فقط پیش‌نمایش ایستای `index.html` را اجرا می‌کند. فرم‌ها، سبد خرید، ورود، مدیریت، سفارش‌ها و دیتابیس واقعی این برنامه در Pages اجرا نمی‌شوند.

## اجرای برنامه کامل
این پروژه یک برنامه Node.js/Express است و برای اجرای کامل به محیطی با Node.js 18 یا جدیدتر نیاز دارد:

```bash
cp .env.example .env
npm install
npm run seed
npm start
```

سپس `http://localhost:3000` را باز کنید. قبل از اجرا، مقادیر `.env` را شخصی‌سازی کنید. برای استقرار عمومی حتماً رمز مدیر و `SESSION_SECRET` را تغییر دهید و از داده‌های آزمایشی استفاده کنید.

## ساختار پوشه‌ها
- `app.js`: مسیرها و منطق برنامه
- `models/`: اتصال و ساخت دیتابیس SQLite
- `scripts/`: داده‌های نمونه
- `views/`: قالب‌های EJS
- `public/`: فایل‌های CSS، JavaScript و تصاویر
- `uploads/`: محل فایل‌های بارگذاری‌شده
- `data/`: محل دیتابیس محلی
- `index.html`: پیش‌نمایش ایستای مخصوص GitHub Pages

## امکانات
کاتالوگ و جست‌وجوی کالا، فیلتر قطعات، صفحه محصول، سبد خرید نشست‌محور، حساب کاربری، ثبت سفارش، پیگیری سفارش، پرداخت نمایشی و پنل مدیریت.

پرداخت نمایشی تراکنش واقعی انجام نمی‌دهد. از اطلاعات شخصی یا پرداخت واقعی در نسخه دمو استفاده نکنید.
